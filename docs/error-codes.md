\# 错误码



| 码 | 场景 | 前端提示 |

|---|---|---|

| AUTH\_FAILED | Token 无效或缺失 | 登录已失效，请重新登录 |

| AUTH\_EXPIRED | Token 过期 | 登录已过期 |

| TABLE\_NOT\_FOUND | 房间不存在 | 房间不存在 |

| TABLE\_FULL | 房间满 | 房间已满 |

| SEAT\_TAKEN | 座位被占 | 该座位已被占用 |

| SEAT\_INVALID | 座位号非法 | 座位号非法 |

| NOT\_SEATED | 未坐下 | 请先坐下 |

| NOT\_YOUR\_TURN | 不是你的回合 | 还没轮到你 |

| INVALID\_ACTION | 动作非法 | 操作不被允许 |

| STATE\_OUTDATED | 版本过期 | 状态已更新，请重试 |

| INSUFFICIENT\_CHIPS | 筹码不足 | 筹码不足 |

| HAND\_NOT\_ACTIVE | 当前无手牌 | 当前没有进行中的牌局 |

| RATE\_LIMITED | 请求过频 | 操作太快了 |

| INTERNAL\_ERROR | 服务端错误 | 服务异常，请稍后再试 |
